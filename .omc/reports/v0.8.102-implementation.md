## Decisions and small interface additions

- `PreviewFrame` has an optional internal `onPaint` callback in addition to the specified data fields. This carries FrameScreen's successful decode timestamp back to the adapter without changing the capture pipeline or rerendering the conversation for every frame. FrameScreen also accepts the accessible title.
- The existing DTO additionally permits `capture_unavailable`; it maps to the generic unavailable explanation (the spec's reason union contains only permission-denied and unsafe capture).
- `useCompactBrowser` now discovers `.bots-main` before a side pane exists, so the adapter and header use the same observed host geometry after resize. The side pane's state machine and stream effects are unchanged.
- Card max-width accounts for its specified horizontal margins at very narrow widths, keeping it inside its parent rather than overflowing by those margins.
- A `lastSnapshot` translation key supplies the prefix while `snapshotAge` supplies the specified localized duration; obsolete `recent`, `caption` and `snapshot` keys were deleted.
- The existing notice e2e now waits for the preceding transient toast to disappear before injecting the next notice, and gives each fixture notice a unique context. This avoids an earlier toast's dismissal timer racing the next assertion; product toast code was not changed.
- Existing files over 400 lines remain existing files; all new implementation/test files are below 400 lines. No extra dependencies were added.
