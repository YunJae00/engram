# v0.8.102 release notes draft

## 한국어

- 앱과 웹 미리보기를 하나의 카드로 통합했습니다.
- macOS 코드 서명을 고정해 앞으로 업데이트 후에도 손쉬운 사용 권한이 유지되도록 했습니다. 실제 업데이트 간 유지 여부는 0.8.103에서 확인할 예정입니다.
- **이번 한 번만:** 0.8.102 설치 후 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 기존 Engram을 **−로 제거**하고 **+로 /Applications/Engram.app을 다시 추가**해 주세요. 이미 켜져 있어도 필요하며, 토글만 껐다 켜는 것으로는 기존 빌드의 권한 기록이 갱신되지 않습니다.
- 자체 서명이며 공증되지 않았으므로 **Open Anyway(확인 없이 열기)** 절차는 이전과 같습니다.

## English

- App and web previews now share one unified card.
- macOS now uses a stable signing certificate so Accessibility permission should persist through future updates. Retention across actual updates will be confirmed with 0.8.103.
- **One time only:** after installing 0.8.102, open System Settings → Privacy & Security → Accessibility, **remove Engram with −**, then **add /Applications/Engram.app again with +**. Do this even if Engram is already enabled; toggling it alone does not update the previous build’s permission record.
- The app remains self-signed and unnotarized. The **Open Anyway** procedure is unchanged.
